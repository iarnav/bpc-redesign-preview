# BPC Indian Community — Redesign Preview

This is a **static HTML/CSS preview** of a proposed redesign for the
[BPC Indian Community](https://bpcindiancommunity.co.uk) website
(Bournemouth, Poole & Christchurch).

It is **not** the live site — it's a prototype for review/feedback before any
changes are made to the real WordPress site. Once approved, the design will be
rebuilt directly on the live WordPress + Elementor site.

## Pages
- `index.html` — Homepage
- `contact.html` — Contact page

## Features
- Fully responsive (desktop, tablet, mobile) with a working hamburger menu
- Light/dark theme toggle (saved per-browser)
- Google Analytics 4 tracking enabled

## Live preview
Published via GitHub Pages: see the repository's **About** section on GitHub
for the live link once Pages finishes deploying.
